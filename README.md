# Rust Companion

Компаньон для игры Rust. Работает через официальный API Rust+ и показывает подсказки
в отдельном окне поверх игры. Процесс игры не трогает: не читает память, не внедряет код,
не отправляет нажатия. Подробности и план развития: [PLAN.md](PLAN.md).

Сейчас готов **этап 0**: клиент Rust+ (через relay Facepunch, как требуется с 5 ноября 2026),
сопряжение через push-уведомления, консольная утилита `rcomp` и фейковый сервер для разработки.

## Установка

Нужен [Node.js](https://nodejs.org/) 20 или новее.

```bash
git clone https://github.com/timuriwecode/rust.git
```

```bash
cd rust
```

```bash
npm install
```

Проверка, что всё собралось (типы + тесты):

```bash
npm run check
```

## Попробовать без игры

В одном терминале запусти фейковый сервер:

```bash
npm run cli -- fake-server
```

Во втором терминале:

```bash
npm run cli -- status --direct 127.0.0.1:28082
```

Другие команды: `markers`, `chat`, `chat привет`, `entity 1003`, `entity 1001 on`,
`map --out map.jpg`, `record --minutes 1`. Все с `--direct 127.0.0.1:28082`.

## Первый запуск на реальном сервере

Секреты (токен входа, FCM-ключи, playerToken) хранятся только локально в
`%APPDATA%\rust-companion\config.json`. Папку можно сменить переменной `RCOMP_HOME`.
Этот файл не коммить и никому не отправляй.

**1. Токен входа Rust+ (Steam).** Команда покажет ссылку и пошаговую инструкцию:

```bash
npm run cli -- login-url
```

Пройди шаги, скопируй ссылку `rust-plus://rust-auth-session/?token=…` и сохрани её:

```bash
npm run cli -- auth "rust-plus://rust-auth-session/?token=..."
```

**2. Регистрация этого ПК для push-уведомлений Rust+:**

```bash
npm run cli -- register
```

**3. Сопряжение.** Запусти приём уведомлений и не закрывай его:

```bash
npm run cli -- listen
```

Затем в игре: `Esc → Rust+ → Pair with Server`. В терминале появится «Сервер сопряжён».
Смарт-устройства (выключатель, сигнализация, storage monitor) сопрягаются так: смотришь
на устройство, зажимаешь `E`, выбираешь «Pair».

**4. Проверка:**

```bash
npm run cli -- servers
```

```bash
npm run cli -- status
```

**5. Запись трафика для тестов** (10 минут, SteamID и ники заменяются псевдонимами):

```bash
npm run cli -- record --minutes 10 --redact
```

Файл появится в папке `recordings/`. Её содержимое не попадает в git.

## Структура

```
packages/core      клиент Rust+, protobuf-схема, ограничитель запросов, типы, сетка карты,
                   запись трафика; core/testing — фейковый сервер
packages/pairing   FCM-регистрация, приём уведомлений о сопряжении, локальное хранилище
tools/cli          утилита rcomp
```

## Что известно об изменениях Rust+ в 2026 году

- **6 августа:** сервер больше не отдаёт в Rust+ торговые автоматы, грузовой корабль,
  вертолёты и странствующего торговца.
- **Октябрь:** вход через Steam заканчивается ссылкой `rust-plus://…` с токеном. Токен живёт
  около 14 дней.
- **5 ноября:** подключение к серверам идёт только через relay Facepunch. Нужны токен входа
  и `id` сервера из нового уведомления о сопряжении. Серверы, сопряжённые раньше, нужно
  сопрячь заново.
